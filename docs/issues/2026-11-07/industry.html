Agent security and policy

The Hacker News: 3 days ago · 3m
Researchers Uncover Prompt Adware Hidden in OpenAI Codex Jailbreak Toolkit  —  Check Point Research disclosed details of Haiou (Seagull), an OpenAI Codex configuration and jailbreak package that injects persistent advertisements into an AI agent's responses. Rather than using conventional executable malware, the bundle alters Codex configuration files through natural-language prompts so that common greetings trigger advertisements for an opaque, third-party LLM gateway. The toolkit has been forked 77 times and bundled into third-party UI managers. Researchers warned that as AI agents rely on shared skills and configuration files, prompt-level manipulation represents an emerging supply-chain attack vector that evades standard endpoint security tools.
Takeaway: Directly relevant to your work on agent skills, configuration files, and prompt optimization, illustrating how third-party instruction files can compromise agent trust boundaries.

Arcjet also introduced early access for specialized models, including Arcjet Thebe 1 for coding agents, which distinguishes legitimate terminal commands and code syntax from malicious injections to minimize false positives in high-privilege execution environments.
Takeaway: Useful for your agent runtime and guardrail evaluations, offering a low-latency alternative to LLM-as-judge checks for detecting prompt injection before tool execution.
