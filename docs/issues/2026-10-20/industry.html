Research and benchmarks

arXiv: Oct 8 · 10m
LLM judges flip verdicts on reruns and answer-order swaps; one fully repeatable judge was right only 51% of the time  —  A reliability audit of LLM-as-a-judge runs six frontier models across four benchmarks, five prompt formats, two presentation orders, three temperatures and ten repeats. Verdicts change between identical runs even at temperature zero, swapping answer order flips most verdicts on hard tasks, and one perfectly repeatable judge matched ground truth only 51% of the time. The authors propose a trustworthy verdict rate and find holistic rubric scoring beats pairwise win-rate prompting.
Takeaway: Directly relevant to your LLM-as-judge reliability work: it separates determinism from accuracy and offers a metric combining reproducibility, order-invariance and correctness that you could add to judge checks.
GitHub (stanfordnlp/dspy): Oct 12 · 4m
DSPy 3.4.1 makes GEPA's structured instruction proposer the default  —  DSPy 3.4.1 changes how GEPA reflects: the reflection model is now called through dspy.Predict with a JSON adapter, so tool trajectories, history and images arrive as structured content. New proposer options include reference skills, extra instructions and a hard character cap. The reflection LM must now return JSON, and the notes warn that results can differ from 3.4.0 even with the same seed. It also adds Python 3.15 support.
Takeaway: Affects your GEPA prompt-optimization work: re-baseline any benchmark that compares GEPA runs across 3.4.0 and 3.4.1, and check that your reflection model can return JSON.
Arize AI blog: Oct 7 · 8m
Reversing a question's wording flipped several small judge models from good to worse than chance  —  Arize benchmarked eight small decision models (classifiers that return a probability per option) as judges for hallucination detection, evaluator suites and agent routing. Accuracy among the leaders was within about a point. The notable result: rewording the RAGTruth question to reverse its polarity on 1,338 rows dropped Liquid d1 from 0.92 to 0.17 ROC AUC and Strands Decider from 0.75 to 0.26, while Jev held at 0.93. This is a vendor-run benchmark.
Takeaway: Bears on your judge-reliability checks: swapping the judge model can silently invert scores, so testing both phrasings of each rubric question is a cheap guard to add to evaluation pipelines.
arXiv: Oct 1 · 10m
Agents Are Systems, Not Models: about 54% of outcome variance comes from rerunning the same configuration  —  Researchers build a benchmark of four scientific tasks in which a coding agent must find and correctly operate a published specialist model, then vary five configuration parts: task information, reasoning, self-verification, time budget and backbone model. Rerunning one configuration explains about 54% of outcome variance, and task information mattered more than time budget or model size. A dedicated verification tool changed behaviour far more than prompting to verify. Over 18,000 trajectories are released.
Takeaway: Useful for your agent-evaluation design: single runs are noisy and system configuration, not only the model, drives results, which informs repeat counts and how you compare agent variants.
Google Developers Blog: 5 days ago · 7m
Google's practical rollout for agent evals: read traces by hand first, then automate, then validate the judge  —  Google lays out a Day 0 to Day 2 plan for agent evaluation: read raw execution traces and mark failures by hand, turn those notes into deterministic assertions and boolean judge rubrics, rerun the same battery on every prompt, model or tool change, and check any new LLM judge against the hand-graded traces. It says production quality often takes 50 to 60 small tuning iterations and pairs OpenTelemetry traces with Gemini's agent evaluation service.
Takeaway: Matches your trace-level evaluation and judge-validation practice, and gives a concrete cadence for calibrating LLM judges against hand-graded traces.
Apache SkyWalking blog: 5 days ago · 5m
Apache SkyWalking 11.1.0 will run LLM-as-judge on production GenAI traces  —  The upcoming SkyWalking 11.1.0 adds an asynchronous judge module: sampled GenAI spans that carry both input and output messages are sent to an OpenAI-compatible judge model, and the results attach to an evaluation record and the source trace. Score-type tasks also feed a dashboard metric and alarms. The module is off by default and needs a snapshot build of the server until the release ships.
Takeaway: An open-source example of online LLM evaluation inside an observability stack, comparable to the Langfuse and LangSmith evaluators you follow, and relevant to your agent-observability interest.

Products, tools and launches

OpenCode changelog: today · 4m
OpenCode 2.1.0 changes SDK, event and plugin contracts and adds Windows persistent terminals  —  OpenCode 2.1.0 shipped on 20 October with deliberate breaking changes to the public SDK, HTTP message/event and plugin contracts: provider replay data is now called native, compaction events drop recent in favour of a keepID reference, and session.compacted is removed. Stored sessions stay readable with no migration. It also adds persistent terminals on Windows, an experimental todowrite tool, session archiving and earlier summary compaction by default.
Takeaway: You use OpenCode and OpenChamber daily and build agent automation around them; any plugin or SDK code needs the renamed native and compaction fields.
Pydantic AI security advisory (GitHub): today · 4m
Pydantic AI 2.58.0 fixes MCP credentials leaking into OpenTelemetry traces  —  A medium-severity advisory (CVSS 6.5) says that with request instrumentation enabled, provider-native MCP tools could export server URLs, authorization tokens and custom header values in OpenTelemetry request traces, even with include_content=False. Anyone who can read those traces could see them. Fixed in pydantic-ai 2.58.0 and 1.107.8; the maintainers advise upgrading, restricting access to historical traces and rotating exposed credentials. The same release patches a second UI-adapter advisory.
Takeaway: Pydantic AI, MCP and OpenTelemetry tracing are all in your tool set; any agent traces that include provider-native MCP could be holding live tokens in an observability backend.
x.ai: Oct 12 · 4m
Cursor joins The X Subscription: new tiers from $8 to $200 and a shared Grok usage pool  —  On 12 October Cursor was bundled with Grok, Grok Bot and X Premium into The X Subscription: Free, Plus $8, Premium $30, Super $100 and Ultra $200 per month. Paid plans share one pool of Grok usage across Grok and Cursor, and third-party models stay available in Cursor on Premium and above but are billed separately at API list prices through top-ups. Existing Cursor subscribers can keep their plan or switch for a prorated refund.
Takeaway: You use Cursor and follow AI subscription pricing; this replaces Cursor's own tiers and changes how third-party model usage is billed.
Claude Code Docs: 6 days ago · 5m
Claude Code 2.1.300-2.1.304: GenAI trace attributes, auto-mode decision events and a resume-cost warning  —  Releases 2.1.300 to 2.1.304 (14-19 October) add OpenTelemetry GenAI semantic-convention attributes on trace spans, a split of cache writes into 5-minute and 1-hour lifetimes on api_request events, and classifier verdict and permission mode on tool_decision events. They also add /auto-mode-setup, an /advisor command on Claude Platform on AWS, and a warning on Pro and Max plans when resuming an idle conversation would use a noticeable share of the 5-hour limit.
Takeaway: Standard GenAI span attributes and auto-mode decision events can feed straight into your agent-observability and evaluation pipelines, and you use Claude Code daily.
Langfuse changelog: yesterday · 3m
Langfuse Experiments page charts every score and compares candidate runs against a baseline  —  Langfuse's Experiments page now plots every score across runs, shows summary statistics per score against a baseline run, and lets you compare candidates item by item filtered by score thresholds so regressions come first. You can also choose which metrics appear as columns, step through items with keyboard shortcuts and add a human score, corrected output or comment inside the comparison.
Takeaway: Baseline-versus-candidate comparison with score thresholds maps onto your agent-evaluation and prompt-optimization benchmarking, and Langfuse is one of the tools you track.
LangChain blog: 7 days ago · 6m
LangSmith AI Search finds traces by described behaviour, not just filters  —  LangChain added AI Search to LangSmith: describe a behaviour in plain language, such as whether a user got frustrated or PII leaked, and it returns the matching traces. A fast decision model reads the trace text instead of relying on lossy embeddings, running on SmithDB trajectories, and the search combines with existing filters like errors or tags. It is aimed at finding needle-in-haystack failures and dataset candidates ad hoc.
Takeaway: Trace-level search for failure patterns maps to your agent-observability and evaluation work, and LangSmith is on your list of tools to follow.

GitHub Copilot retires GPT-5.5, GPT-5.4 and other models; more removals set for 16 November  —  GitHub deprecated Gemini 3.7 Flash, GPT-5.5, GPT-5.4, GPT-5.4 mini, GPT-5 mini and Grok 4.5 across most Copilot experiences on 19 October, suggesting Gemini 3.8 Flash, GPT-6.1 Sol, GPT-6 Luna and Grok 4.7 instead. Decagon: Sep 15 · 7m
Decagon's GEPA-GAN: adversarial prompt optimization for realistic simulated customers  —  Decagon uses GEPA to optimize two prompts against each other: a generator that writes the next simulated customer turn and a judge that picks the real reply from a randomized A/B pair. Across 11 checkpoints the internal fool rate swung, peaking at 44% then falling to 30%, while the generator prompt more than doubled in length. Human raters were fooled 34% of the time against 30% for the seed prompt. The authors recommend a length penalty with GEPA.
Takeaway: A competitor's engineering write-up using GEPA, the prompt optimizer you track, with a judge-versus-generator setup relevant to LLM-as-judge reliability and the realism of simulated users in agent evaluation.
Microsoft Copilot Blog: 5 days ago · 5m
Copilot Studio adds agent accounts, business process memory and triggers  —  Microsoft added agent accounts, business process memory and triggers to Copilot Studio. An agent account gives an agent its own credentials in Microsoft 365, so people can @mention it in Word, Excel and PowerPoint comments or assign work from Teams and Outlook, and its actions are attributable to it. Triggers let agents on the GitHub Copilot harness start from an email or a schedule without a prompt. Ooredoo Qatar is cited as an early customer.
Takeaway: Microsoft is a tracked enterprise platform; agent identity, attributable actions and always-on triggers bear on agent observability and on how competing platforms handle governance.
Decagon: today · 6m
Decagon: a guide to serving customers' personal agents  —  Decagon published guidance for businesses on handling customers' personal agents, noting that Meta's Muse passed 5 million downloads within weeks and that some request types are already raising contact volume and handle time. Its five principles include detecting agents to route and measure them rather than block them, offering a dedicated agent channel, and scoping what agents may do by reversibility and legal need. It points to its PACT protocol for verifying identity and permissions.
Takeaway: Personal agents arriving at brand and customer-service agents is a live theme for conversational brand agents, and Decagon is one of the competitors you follow.
AWS What's New: today · 2m
Amazon Bedrock Advanced Prompt Optimization adds prompt shortening  —  Amazon Bedrock Advanced Prompt Optimization now has an optional prompt shortening setting. It returns an optimized prompt only if it is shorter than the original and scores at least as well on your evaluation; otherwise you keep the original. Results report a compression ratio and token counts, and it works with LLM-as-a-judge rubrics and custom Lambda evaluators. Shorter prompts cut input token cost and time to first token.
Takeaway: Ties directly to your prompt-optimization and LLM-as-judge interests: a managed optimizer that accepts judge rubrics and trades prompt length against evaluation score.
Salesforce Newsroom: 5 days ago · 3m
Tottenham Hotspur launches Ask Spurs, an Agentforce fan-support agent  —  Tottenham Hotspur launched Ask Spurs, a multilingual Agentforce agent on its website and app covering ticketing, memberships, retail and stadium events, in eleven languages for logged-in members and guests. Salesforce reports an 86% engagement rate and 20% of interactions resolved by the agent alone, with handoff to human support otherwise. The club unified over 4.6 million fan accounts across more than 10 systems.
