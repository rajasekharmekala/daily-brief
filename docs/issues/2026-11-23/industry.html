Products, tools and launches

Anthropic: today · 4m
Anthropic launches Claude Ship beta to review, fix, and approve GitHub PRs  —  Anthropic launched Claude Ship in beta on Nov 23, combining generally available Code Review with two new GitHub agents: PR Steward and Claude Approvals. PR Steward resolves failing CI checks, merge conflicts, and review feedback while commenting how to undo pushes, and Claude Approvals evaluates repository-hosted natural-language policy files to auto-approve routine changes or escalate sensitive ones. Developers trigger it via `/ship` in Claude Code or enable it per repo with Quick, Standard, or Deep review modes, monthly spend caps, and observe-only rollout; internal Claude Code usage more than doubled merged PRs while cutting reverts over 40%.
Takeaway: Directly extends your Claude Code workflow from code generation into automated CI remediation and policy-based PR approvals.
LangChain: 4 days ago · 5m
LangSmith Tool Gateway enters Public Beta for governed agent tool calls and auth  —  LangChain released LangSmith Tool Gateway in Public Beta on Nov 19 as a managed governance layer paired with its LLM Gateway on the LangSmith Agent Platform. Designed for production deployments spanning dozens of MCP servers and over a thousand tools, it separates tool definitions from OAuth tokens, enforcing per-user or service-account credentials, curated per-agent tool subsets, and approval policies without hand-rolled auth code. Every tool invocation, server, user identity, latency, and outcome is logged directly inside LangSmith traces for compliance auditing; it remains in Public Beta.
Takeaway: Pairs centralized MCP credential scoping and audit trails with the LangSmith observability stack in your production-agent work.
GitHub: today · 3m
OpenAI Codex CLI v0.172.0 adds lazy stdio MCP startup, thread links, and Bedrock setup  —  OpenAI shipped Codex CLI v0.172.0 on Nov 23 PT (Nov 24 UTC), refining multi-agent terminal navigation and MCP runtime behavior. Optional stdio MCP servers with cached tool lists now launch lazily on their first tool call, `config.toml` supports per-app approval reviewers, and app-server clients can choose Amazon Bedrock Runtime during setup or sign-in. The release also adds slash-command argument tab completion, `Shift+Up`/`Down` task-group jumps, thread links for opening nested agents, preserved sandbox permissions on `codex exec resume`, gRPC-only Code Mode host connections, and updated GPT-6.2 Astra and Sol migration docs.
Takeaway: Lazy MCP server startup and preserved sandbox permissions directly improve daily Codex CLI speed and harness reliability.

The real-time voice model improves cross-language accent consistency, recognition of exact letters and numbers, full-duplex listening while speaking, and delegation to separate backend models mid-conversation. Takeaway: Relevant to your real-time voice AI and cost-comparison work with a 60% cheaper idle WebRTC Standby billing tier.

Crypto Briefing: today · 3m
Anthropic opens Enterprise Frontier Safeguards public beta with zero data retention  —  Anthropic opened Enterprise Frontier Safeguards (EFS) in public beta on Nov 23 for Claude Platform customers, answering enterprise pushback against its mid-2026 30-day retention policy. Following a private beta with over 100 organizations—including Fortune 100 finance, healthcare, and legal firms—early public-beta participants include Bridgewater, Salesforce, and Stripe. Under EFS, prompts, responses, and reasoning are encrypted with customer-held keys and stored solely in the customer's Amazon S3 or Google Cloud environment with zero Anthropic retention or training, while automated classifiers flag suspected misuse to customer security teams within a week; organizations with HIPAA readiness enabled are currently excluded.
Takeaway: Addresses a major enterprise deployment blocker—zero retention with customer-managed keys—for governed agent platforms.

VentureBeat: 3 days ago · 5m
T-Mobile CIO on why dumping support docs into large contexts worsened AI answers  —  T-Mobile CIO Jeff Simon detailed how stuffing full support documentation into large-context customer-service agents backfired because conflicting corporate guides misled routing, and a follow-up knowledge graph proved too slow. T-Mobile switched to a key-value lookup table mapping customer phrasings to scoped agent paths, plus a small LLM judge running on every live chat and voice session to flag errors and caller frustration. Supporting data from VentureBeat's October VB Pulse survey of 97 firms found 78% traced confident wrong agent answers to missing or inconsistent context over six months, with 42% reaching external parties or forcing reversals.
Takeaway: Concrete enterprise lesson combining context-pruning architecture with production LLM-as-judge monitoring on every session.

The Next Web: today · 4m
Z.ai launches GLM-5.4, a 750B Loop Transformer targeting Generalized Coding  —  Z.ai (Zhipu AI) released GLM-5.4 on Nov 23, its first flagship built on a Loop Transformer that runs 28 layers of its 750B GLM-5 base model twice per pass while reusing first-pass KV caches to deepen computation without adding parameters. Z.ai claims (vendor-reported; no GLM-5.4 benchmark table published yet) parity with 2T–3T parameter models, adding vision for visual coding and demos spanning games, 3D shaders, and FreeCAD modeling at up to 200 tokens/s off-peak (70–80 peak). Available now to GLM Coding Plan subscribers with 50% higher weekly quotas than GLM-5.3, with API access and open weights planned after safety checks; Z.ai noted occasional "marathon thinking" loops.
Takeaway: Tests whether looped-layer compute scaling can replace sheer parameter growth on complex coding and multimodal tasks.
Artificial Analysis: 3 days ago · 3m
Thinking Machines Lab ships Inkling 2 Mini open-weight looped MoE for local laptops  —  Thinking Machines Lab released Inkling 2 Mini on Nov 20 under an Apache 2.0 license: a 26B-total, 5.4B-active multimodal MoE with 1M context that loops 12 middle layers three times per token (3.1B unique weights per pass), small enough for a MacBook or DGX Spark. In independent Artificial Analysis testing, it scores 20 on the Intelligence Index—tying Qwen3.8 27B (xhigh) and Nanbeige4.3-33B with ~5x–6x fewer active parameters, ~2.8x less compute, and 9.0-minute / $0.59 per-task cost (at Thinking Machines' $0.15/$0.50/$0.015 per 1M input/output/cached pricing) versus 38.2 minutes and $3.53 for Qwen3.8 27B, despite emitting ~38% more output tokens.
Takeaway: Gives you a fast, Apache 2.0 local multimodal model benchmarked independently on cost-per-task and tool-use efficiency.
