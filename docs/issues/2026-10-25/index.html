arXiv: Oct 2 · 18m
A trajectory test exposes gaps in outcome-only LLM judges  —  The paper tests LLM judges by injecting known faults into clean agent runs and comparing each faulty trace with its parent. A judge shown only the request and final answer reported 34% to 76% recall for faults that left the reply unchanged, but its paired discrimination was zero. A step-aware prompt flagged every tested fault in those categories while flagging none of 100 clean runs; the authors recommend reporting both fault detection and clean-run false alarms.
Takeaway: This is directly relevant to your LLM-as-judge reliability work because it distinguishes apparent recall from actual fault discrimination.
